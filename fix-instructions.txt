// Fix for navigation and dark mode issues

1. To fix navigation and footer not being clickable from quote generator page:
   - Open app/dailyquotes/page.js
   - Find the fixed background div 
   - Add `z-index: 0` to the style object of that div
   - Ensure all content elements have higher z-index values

2. To fix dark theme not working correctly on home page:
   - Open components/ThemeWrapper.js
   - Replace the current return statement with:
   ```jsx
   return (
     <div className={`min-h-[100vh] ${darkMode ? "dark bg-background dark:text-foreground" : "bg-background text-foreground"}`}>
       <NotificationInitializer />
       {children}
     </div>
   );
   ```

3. To fix header navigation to adjust in mobile screen size:
   - Open components/navigation.js
   - In the main div container, add `flex-wrap` to the class list
   - Make the logo more responsive by adding `flex-shrink-0 mr-4`
   - Update navigation links container to use `text-sm lg:text-lg` and `gap-4 lg:gap-6`
   - Add `flex-grow justify-center` to better center the navigation
   - Update the mobile menu to use less vertical space

These changes will resolve the three issues:
1. Navigation and footer clickability on the quote generator page
2. Dark theme consistency across the application
3. Mobile responsiveness of the header navigation
